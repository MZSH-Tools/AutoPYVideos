# AutoPYVideos Manager 设计文档

## 需求概述

独立的后台管理程序：
1. 后台常驻运行，系统托盘显示图标
2. 右键托盘图标可打开管理界面、暂停、退出
3. 管理界面支持添加 YouTube 链接、配置翻译选项
4. 自动下载视频并调用 videotrans 处理
5. 查看当前任务和历史记录

---

## 项目结构

```
manager/
├── __init__.py       # 模块入口
├── app.py            # 应用程序主类
├── tray.py           # 系统托盘模块
└── main_window.py    # 管理界面主窗口

run_manager.py        # 启动脚本
```
