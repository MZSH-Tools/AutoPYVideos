# AutoPYVideos Manager 设计文档

## 项目概述

**英文视频中文化工具**：将英文视频自动转换为中文字幕和配音
- 全程 **CPU 模式**（无 GPU 加速）
- 流程：下载 → 提取音频 → 英文语音识别 → 翻译成中文 → 中文配音 → 合成视频

## 环境配置

- **Conda 环境名**: `AutoPYVideos`
- **Python 版本**: 3.10
- **运行模式**: CPU（默认强制 CPU，不使用 GPU）
- **主要依赖**:
  - PySide6（GUI）
  - yt-dlp（YouTube 下载）
  - psutil（进程检测）
  - ffmpeg（视频处理，通过 conda 安装）
  - faster-whisper（语音识别，CPU 模式，medium 模型）
  - edge-tts（微软免费 TTS 配音）

```bash
# 创建环境
conda create -n AutoPYVideos python=3.10
conda activate AutoPYVideos

# 安装依赖
pip install PySide6 yt-dlp psutil faster-whisper edge-tts
conda install -c conda-forge ffmpeg x264 expat
```

**注意**：ffmpeg 需要从 conda-forge 安装，确保包含 libx264 编码器（硬字幕烧录需要）

## 需求概述

独立的后台管理程序：
1. 后台常驻运行，系统托盘显示图标
2. 右键托盘图标可打开管理界面、退出
3. 管理界面支持添加 YouTube 链接、查看任务状态
4. **全自动流水线处理**：添加链接后自动下载→提取→识别→翻译→配音→合成
5. **同时只处理一个视频**，完成后自动处理下一个
6. 主界面默认选中正在处理的视频
7. 查看当前任务和历史记录

## 任务状态（6 阶段流水线）

| 状态 | 颜色 | 说明 | 完成标志文件 |
|------|------|------|--------------|
| Queued | 灰色 | 等待开始 | - |
| Downloading | 蓝色 | 下载中 | `video.mp4` |
| Extracting | 橙色 | 提取音频中 | `audio.wav` |
| Recognizing | 橙色 | 识别中 | `en.srt` |
| Translating | 橙色 | 翻译中 | `zh-cn.srt` |
| Dubbing | 橙色 | 配音中 | `zh-cn.wav` |
| Merging | 橙色 | 合成中 | `output.mp4` |
| Ready | 绿色 | 待发布 | - |
| Published | 深灰 | 已发布 | `info.json` 中有 `PublishUrl` |

### 文件夹驱动的断点续传

**核心设计**：程序启动时遍历任务文件夹，根据存在的文件推断状态，无需全局 Tasks.json

```
状态推断逻辑（按优先级）：
1. info.json 有 PublishUrl → Published
2. output.mp4 存在 → Ready
3. zh-cn.wav 存在 → Merging
4. zh-cn.srt 存在 → Dubbing
5. en.srt 存在 → Translating
6. audio.wav 存在 → Recognizing
7. video.mp4 存在 → Extracting
8. 只有 info.json → Queued
```

## 缓存位置

- Windows: `%LOCALAPPDATA%/AutoPYVideos/`
- macOS/Linux: `~/.local/share/AutoPYVideos/`

```
AutoPYVideos/
└── Tasks/
    └── {时间戳Key}/              # 每个任务独立文件夹
        ├── info.json             # 任务元信息（URL、标题、作者、发布链接）
        ├── video.mp4             # 下载的原始视频（最高1080p）
        ├── video_slow.mp4        # 慢速后的视频（视频慢速模式生成）
        ├── audio.wav             # 提取的音频（16kHz 单声道）

        ├── bilingual.srt         # 双语字幕（中文在上，英文在下）
```

```json

  "VideoId": "YouTube视频ID",
  "PublishUrl": "发布后的链接",

}
```

## 与 videotrans 的关系

本项目基于 [pyvideotrans](https://github.com/jianchang512/pyvideotrans) 构建，复用其核心模块：

| 功能 | 调用模块 | 说明 |
|------|----------|------|
| FFmpeg 执行 | `videotrans.util.help_ffmpeg.runffmpeg` | 自动检测硬件编码器，统一错误处理 |
| 音频提取 | `runffmpeg` | 提取 16kHz 单声道 wav |
| 语音识别 | `videotrans.recognition.run` | Faster-Whisper，自动检测 CUDA |
| 翻译 | `videotrans.translator.run` | 默认 Google，失败自动回退 Microsoft |
| 配音 | `videotrans.tts.run` | Edge-TTS，支持多种 TTS 引擎 |
| 配音对齐 | `videotrans.task._rate.SpeedRate` | 配音时长自动加速对齐字幕时长 |
| 合成 | `runffmpeg` | 硬字幕烧录 + 音视频合并 |

manager 目录下的模块主要负责：
- 任务管理和队列调度（Task.py）
- GUI 界面（MainWindow.py、Tray.py）
- YouTube 下载（Download.py，yt-dlp，videotrans 无此功能）

**全部核心处理流程调用 videotrans 接口**：
- 音频提取（Extract.py → `runffmpeg`）
- 语音识别（Recognize.py → `recognition.run`）
- 翻译（Translate.py → `translator.run`）
- 配音（Dubbing.py → `tts.run` + `SpeedRate`）
- 合成（Merge.py → `runffmpeg`）

### 语音识别配置

**Recognize.py 默认配置**：
- **识别引擎**：Faster-Whisper（`recognition.FASTER_WHISPER`）
- **模型**：`small.en`（英语专用模型，速度快、准确率高）
- **语言**：`en`（英语）
- **分割方式**：`split_type=0`（整体识别，非均等分割）
- **LLM 重新断句**：关闭（`config.settings['rephrase'] = 0`）
- **自动修正**：启用（`AutoFix=True`，调用 `tools.auto_fix_srtdict()`）

**参数说明**：
| 参数 | 值 | 说明 |
|------|------|------|
| Model | `small.en` | 英语专用模型，比通用 small 更快更准 |
| SplitType | `0` | 整体识别（1=均等分割） |
| AutoFix | `True` | 自动修正字幕时间轴和文本 |
| rephrase | `0` | 不使用 LLM 重新断句 |

### 翻译配置

**Translate.py 默认配置**：
- **翻译引擎**：Google Translate（`translator.GOOGLE_INDEX`）
- **源语言**：`en`（英语）
- **目标语言**：`zh-cn`（简体中文）

### 配音配置

**Dubbing.py 设计原则**：
- **完全使用 videotrans 接口**，不实现备用方案
- 有错误直接抛出异常，不做降级处理
- 调用 `tts.run()` 生成配音，调用 `SpeedRate` 对齐时间轴

**默认配置**：
- **TTS 引擎**：Edge-TTS（`tts.EDGE_TTS`）
- **配音角色**：`晓晓 多语言(Female\CN)`（注意是反斜杠）
- **Voice ID**：`zh-CN-XiaoxiaoMultilingualNeural`
- **语速**：`voice_rate`（来自 `cfg.json`，默认 `+100%`）
- **配音自动加速**：关闭（`VoiceAutorate=False`）
- **视频慢放**：启用（`VideoSlowdown=True`）

### 对齐控制配置

**SpeedRate 参数**：
| 参数 | 值 | 说明 |
|------|------|------|
| shoud_audiorate | `False` | 配音加速（不勾选） |
| shoud_videorate | `True` | 视频慢速（勾选） |
| remove_silent_mid | `False` | 删除中间静音（不勾选） |
| align_sub_audio | `True` | 字幕音频对齐 |

**视频慢速模式**：
- 视频慢速后保存为 `video_slow.mp4`，原视频 `video.mp4` 保持不变
- 生成对齐版双语字幕 `aligned_bilingual.srt`（时间轴与慢速视频匹配）
- 合成时优先使用 `video_slow.mp4` 和 `aligned_bilingual.srt`

### 字幕嵌入配置

**subtitle_type 类型**（参考 `videotrans/task/taskcfg.py`）：
| 值 | 说明 |
|------|------|
| 0 | 不嵌入 |
| 1 | 硬字幕（单） |
| 2 | 软字幕（单） |
| 3 | 双硬字幕 |
| 4 | 双软字幕 |

**当前配置**：使用 **双硬字幕**（中文在上，英文在下）
- 翻译完成后调用 `MergeBilingualSrt()` 合并双语字幕
- 合成时使用 `bilingual.srt` 烧录硬字幕

### 状态检查绕过

videotrans 的 `recognition.run()` 和 `tts.run()` 内部有状态检查：
```python
# recognition
if config.exit_soft or (config.current_status != 'ing' and config.box_recogn != 'ing'):
    return

# tts
if config.exit_soft or (config.current_status != 'ing' and config.box_tts != 'ing'):
    return
```

解决方案：调用前临时设置 `config.box_recogn = 'ing'` 或 `config.box_tts = 'ing'`，调用后恢复

### 配音对齐（SpeedRate）

配音与字幕时长对齐使用 `videotrans.task._rate.SpeedRate` 类：

**问题**：中文配音时长通常比英文字幕时长更长，导致"话赶话"

**解决方案**：
- `VoiceAutorate=True`（默认启用）：配音自动加速，确保配音在字幕时间内播放完成
- 使用 `atempo` 或 `rubberband` 滤镜进行高质量音频变速
- 最大加速倍数由 `cfg.json` 中 `max_audio_speed_rate` 控制（默认 100%）

**相关配置（videotrans/cfg.json）**：
```json
{
  "max_audio_speed_rate": 100,  // 配音最大加速倍数（100 = 2倍速）
  "max_video_pts_rate": 10      // 视频最大减速倍数（暂未使用）
}
```

**Dubbing.py 调用流程**：
1. 验证声音名称有效性（`get_edge_rolelist()`）
2. 构建 `queue_tts` 列表，`role` 使用原始中文名称（EdgeTTS 内部会转换）
3. 调用 `tts.run()` 生成配音片段（每个字幕一个 wav 文件）
4. 调用 `SpeedRate.run()` 对齐并合并：
   - 检查每段配音时长是否超过字幕时长
   - 超过则使用 ffmpeg atempo 加速（或视频慢放）
   - 合并所有片段为最终配音文件
5. 视频慢放时生成对齐字幕 `aligned.srt`

**注意**：
- `queue_tts` 中的 `role` 必须使用中文名称（如 `晓晓 多语言(Female\CN)`），不能使用 VoiceId
- EdgeTTS 内部会调用 `get_edge_rolelist(it['role'], self.language)` 进行转换
- 如果传入已转换的 VoiceId，会导致 `voice must be str` 错误

### 全局配置（cfg.json）

所有模块统一使用 videotrans 配置文件 `videotrans/cfg.json`：

```json
{
  "proxy": "http://127.0.0.1:7890",
  "voice_rate": "+100%",
  "voice_autorate": true,
  "video_autorate": false
}
```

**重要配置项**：
| 配置项 | 默认值 | 说明 |
|--------|--------|------|
| proxy | `http://127.0.0.1:7890` | 代理地址 |
| voice_rate | `+100%` | 配音语速（+加速，-减速） |
| voice_autorate | `true` | 配音自动加速（配音时长超过字幕时长时加速） |
| video_autorate | `false` | 视频自动减速（配音时长超过字幕时长时减速视频） |

**注意**：如果 `cfg.json` 是旧版本生成的，可能缺少新配置项。删除 `cfg.json` 后重启程序会重新生成完整配置。
