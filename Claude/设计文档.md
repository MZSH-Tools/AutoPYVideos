# AutoPYVideos Manager 设计文档

## 需求概述

独立的后台管理程序：
1. 后台常驻运行，系统托盘显示图标
2. 右键托盘图标可打开管理界面、退出
3. 管理界面支持添加 YouTube 链接、查看任务状态
4. 自动下载视频并调用 videotrans 处理
5. 查看当前任务和历史记录

---

## 项目结构

```
manager/
├── App.py            # 应用程序主类
├── Tray.py           # 系统托盘模块
├── MainWindow.py     # 管理界面主窗口
├── Cache.py          # 缓存和任务管理
└── README.md

RunManager.py         # 启动脚本
StartManager.bat      # Windows 启动批处理
```

---

## 任务状态

| 状态 | 颜色 | 说明 |
|------|------|------|
| Queued | 灰色 | 等待下载 |
| Downloading | 蓝色 | 下载中 |
| Processing | 橙色 | 视频处理中 |
| Ready | 绿色 | 处理完成待发布 |
| Published | 深灰 | 已发布 |

## 缓存位置

- Windows: `%LOCALAPPDATA%/AutoPYVideos/`
- macOS: `~/.cache/AutoPYVideos/`

```
AutoPYVideos/
├── Videos/         # 处理后的视频
└── Tasks.json      # 任务记录
```
