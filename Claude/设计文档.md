# AutoPYVideos Manager 设计文档

## 项目概述

**英文视频中文化工具**：将英文视频自动转换为中文字幕和配音
- 全程 **CPU 模式**（无 GPU 加速）
- 流程：下载 → 提取音频 → 英文语音识别 → 翻译成中文 → 中文配音 → 合成视频

## 环境配置

- **Conda 环境名**: `AutoPYVideos`
- **Python 版本**: 3.10
- **运行模式**: CPU（自动检测，无 CUDA 时回退到 CPU）
- **主要依赖**:
  - PySide6（GUI）
  - yt-dlp（YouTube 下载）
  - psutil（进程检测）
  - ffmpeg（视频处理，通过 conda 安装）
  - faster-whisper（语音识别，CPU 模式使用 int8 量化）
  - edge-tts（微软免费 TTS 配音）

```bash
# 创建环境
conda create -n AutoPYVideos python=3.10
conda activate AutoPYVideos

# 安装依赖
pip install PySide6 yt-dlp psutil faster-whisper edge-tts
conda install -c conda-forge ffmpeg x264 expat
```

**注意**：ffmpeg 需要从 conda-forge 安装，确保包含 libx264 编码器（硬字幕烧录需要）

## 需求概述

独立的后台管理程序：
1. 后台常驻运行，系统托盘显示图标
2. 右键托盘图标可打开管理界面、退出
3. 管理界面支持添加 YouTube 链接、查看任务状态
4. **全自动流水线处理**：添加链接后自动下载→提取→识别→翻译→配音→合成
5. **同时只处理一个视频**，完成后自动处理下一个
6. 主界面默认选中正在处理的视频
7. 查看当前任务和历史记录

## 项目结构

**设计原则**：一个模块一个文件，禁止多功能写在同一文件

```
manager/
├── App.py            # 应用程序主类（单实例检测）
├── Tray.py           # 系统托盘模块
├── MainWindow.py     # 管理界面主窗口
├── Storage.py        # 存储路径管理
├── Task.py           # 任务管理（文件夹驱动）
├── Download.py       # 视频下载模块（yt-dlp）

├── Recognize.py      # 语音识别模块（Faster-Whisper，自动检测 CUDA）
├── Translate.py      # 字幕翻译模块（Google Translate 免费 API）
├── Dubbing.py        # 配音模块（待实现）
├── Merge.py          # 音视频合成模块（待实现）
└── README.md

RunManager.py         # 启动脚本
StartManager.vbs      # Windows 隐藏窗口启动脚本
```

## 任务状态（6 阶段流水线）

| 状态 | 颜色 | 说明 | 完成标志文件 |
|------|------|------|--------------|
| Queued | 灰色 | 等待开始 | - |
| Downloading | 蓝色 | 下载中 | `video.mp4` |
| Extracting | 橙色 | 提取音频中 | `audio.wav` |
| Recognizing | 橙色 | 识别中 | `en.srt` |
| Translating | 橙色 | 翻译中 | `zh-cn.srt` |
| Dubbing | 橙色 | 配音中 | `zh-cn.wav` |
| Merging | 橙色 | 合成中 | `output.mp4` |
| Ready | 绿色 | 待发布 | - |
| Published | 深灰 | 已发布 | `info.json` 中有 `PublishUrl` |

### 文件夹驱动的断点续传

**核心设计**：程序启动时遍历任务文件夹，根据存在的文件推断状态，无需全局 Tasks.json

```
状态推断逻辑（按优先级）：
1. info.json 有 PublishUrl → Published
2. output.mp4 存在 → Ready
3. zh-cn.wav 存在 → Merging
4. zh-cn.srt 存在 → Dubbing
5. en.srt 存在 → Translating
6. audio.wav 存在 → Recognizing
7. video.mp4 存在 → Extracting
8. 只有 info.json → Queued
```

## 缓存位置

- Windows: `%LOCALAPPDATA%/AutoPYVideos/`
- macOS/Linux: `~/.local/share/AutoPYVideos/`

```
AutoPYVideos/
└── Tasks/
    └── {时间戳Key}/              # 每个任务独立文件夹
        ├── info.json             # 任务元信息（URL、标题、作者、发布链接）
        ├── video.mp4             # 下载的原始视频
        ├── audio.wav             # 提取的音频（16kHz 单声道）
        ├── en.srt                # 识别的英文字幕
        ├── zh-cn.srt             # 翻译后的中文字幕
        ├── zh-cn.wav             # 配音音频
        └── output.mp4            # 最终合成视频
```

**info.json 结构**：
```json
{
  "Url": "https://...",
  "Title": "视频标题",
  "Author": "作者",
  "Thumbnail": "缩略图URL",
  "VideoId": "YouTube视频ID",
  "PublishUrl": "发布后的链接",
  "Error": "错误信息"
}
```

## 与 videotrans 的关系

本项目基于 [pyvideotrans](https://github.com/jianchang512/pyvideotrans) 构建，复用其核心模块：

| 功能 | 调用模块 | 说明 |
|------|----------|------|
| FFmpeg 执行 | `videotrans.util.help_ffmpeg.runffmpeg` | 自动检测硬件编码器，统一错误处理 |
| 音频提取 | `videotrans.util.help_ffmpeg.runffmpeg` | 提取 16kHz 单声道 wav |
| 翻译 | `videotrans.translator.run` | 默认 Google，失败自动回退 Microsoft |

manager 目录下的模块主要负责：
- 任务管理和队列调度（Task.py）
- GUI 界面（MainWindow.py、Tray.py）
- YouTube 下载（Download.py）
- 语音识别（Recognize.py，直接用 faster-whisper，不用 videotrans 接口因其有状态检查限制）
- 配音（Dubbing.py，直接用 edge-tts 微软免费 TTS，自己处理时间对齐逻辑）

### 为什么部分模块不调用 videotrans 接口

| 模块 | 原因 |
|------|------|
| Recognize.py | `recognition.run()` 内部检查 `config.current_status`，需要设置 GUI 状态才能调用 |
| Dubbing.py | `tts.run()` 数据格式复杂，且需要状态检查；自己实现的时间对齐逻辑更清晰 |
