# AutoPYVideos Manager 设计文档

## 环境配置

- **Conda 环境名**: `AutoPYVideos`
- **Python 版本**: 3.10
- **主要依赖**:
  - PySide6（GUI）
  - yt-dlp（YouTube 下载）
  - psutil（进程检测）
  - ffmpeg（视频处理，通过 conda 安装）

```bash
# 创建环境
conda create -n AutoPYVideos python=3.10
conda activate AutoPYVideos

# 安装依赖
pip install PySide6 yt-dlp psutil
conda install ffmpeg
```

---

## 需求概述

独立的后台管理程序：
1. 后台常驻运行，系统托盘显示图标
2. 右键托盘图标可打开管理界面、退出
3. 管理界面支持添加 YouTube 链接、查看任务状态
4. **全自动流水线处理**：添加链接后自动下载→识别→翻译→配音→合成
5. **同时只处理一个视频**，完成后自动处理下一个
6. 主界面默认选中正在处理的视频
7. 查看当前任务和历史记录

## 任务状态（5 阶段断点续传）

| 状态 | 颜色 | 说明 | 断点文件 |
|------|------|------|----------|
| Queued | 灰色 | 等待开始 | - |
| Downloading | 蓝色 | 下载中 | `原始视频.mp4` |
| Recognizing | 橙色 | 识别中 | `zh-cn.srt` |
| Translating | 橙色 | 翻译中 | `en.srt` |
| Dubbing | 橙色 | 配音中 | `dubbing_cache/*.wav` |
| Merging | 橙色 | 合成中 | `最终视频.mp4` |
| Ready | 绿色 | 待发布 | - |
| Published | 深灰 | 已发布 | - |

### 断点续传逻辑

程序启动时检查每个任务的断点文件，自动恢复到正确的阶段：
1. 最终视频存在 → Ready（待发布）
2. 配音文件存在 → Merging（从合成开始）
3. 翻译字幕存在 → Dubbing（从配音开始）
4. 识别字幕存在 → Translating（从翻译开始）
5. 原始视频存在 → Recognizing（从识别开始）
6. 否则 → Downloading（从下载开始）

## 缓存位置

- Windows: `%LOCALAPPDATA%/AutoPYVideos/`
- macOS: `~/.cache/AutoPYVideos/`

```
AutoPYVideos/
├── Tasks.json                    # 任务记录
└── Videos/
    └── {时间戳Key}/              # 每个任务独立文件夹
        ├── info.txt              # 任务信息（标题、作者、链接、状态、简介）
        ├── {VideoId}.mp4         # 下载的原始视频
        ├── zh-cn.wav             # 提取的音频（识别用）
        ├── zh-cn.srt             # 识别的原语言字幕
        ├── en.srt                # 翻译后的字幕
        ├── dubbing_cache/        # 配音缓存
        │   └── {md5}.wav         # 每句配音
        └── output.mp4            # 最终合成视频
```

每个任务的所有中间文件都在同一个文件夹内，方便查看和清理。
`info.txt` 会随任务状态自动更新，记录原链接、作者、进度、发布链接和简介。
